═══════════════════════════════════════════════════════════════════════════════
CONTEXTO DO PROJETO
═══════════════════════════════════════════════════════════════════════════════

O projeto hen-place-control possui uma interface desktop PySide6 em migração a partir de uma versão antiga em Streamlit.

A interface trabalha com:

- cadastro de produtos;
- nome, descrição e modo de uso;
- pastas de origem e destino;
- imagens e vídeos;
- variações;
- kits;
- medidas;
- produtos.txt;
- SQLite;
- produção de conteúdo;
- prompts para marketplaces;
- processamento de imagens e vídeos;
- reconhecimento de voz;
- logs;
- tarefas em segundo plano.

A pasta principal do projeto é:

hen-place-control/

Antes de trabalhar, considere especialmente:

- hen-place-control/main.py
- hen-place-control/_APP_/
- hen-place-control/_CONFIGURA_/
- hen-place-control/_LOGS_/
- hen-place-control/_THREADS_/
- hen-place-control/_ULTILIDADES_/
- hen-place-control/_FERRAMENTAS_/
- hen-place-control/_APPDATA_/
- hen-place-control/nucleo/

Leia primeiro os documentos e instruções relevantes para o pedido atual. Não leia ou altere arquivos sem relação com a tarefa.
